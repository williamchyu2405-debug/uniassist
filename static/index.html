Share over the Internet

Let classmates anywhere access UniAssist — even on different networks. Uses a free Cloudflare Tunnel (no port-forwarding, no paid plan needed).

1

Set an access code (keeps strangers out)

Open /Users/will/uniassist/.env and add:

ACCESS_CODE=yourpassword

Then restart UniAssist. Anyone opening the URL has to enter this code first.

2

Install cloudflared (one-time)

brew install cloudflared
3

Start the tunnel (run this in Terminal)

cloudflared tunnel --url http://localhost:8000

It prints a public URL like https://abc-xyz.trycloudflare.com — share that. The URL lasts as long as the Terminal is open.

💡

Want a permanent URL?

Create a free Cloudflare account → run cloudflared tunnel login → create a named tunnel. Your URL never changes, even between restarts.

▸ Same Wi-Fi only (no tunnel)
